PDF Laser Classroom V2 - patched

1. Extract the ZIP.
2. Open index.html in Chrome while connected to the internet.
3. Tap Open PDF and choose a PDF file.

The app now tries three PDF.js CDN providers if the first one fails. Internet is still required to load the PDF engine. The PDF file itself is selected locally and is not uploaded.

Fully offline PDF opening still requires PDF.js library and worker files bundled locally; those could not be downloaded in this build environment.
